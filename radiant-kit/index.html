Radiant Sprite Kit

Download a Pokémon's default sprite sheets to recolour into a radiant form. The files in the .zip come in one folder named for the Pokémon (assets/0150_mewtwo/), with a README for the artist. Once they're recoloured, bring the .zip in with the Radiant Admin on your PC (node fork/radiant-admin.cjs): it checks every sheet, previews it and publishes it.

SheetFile in the .zipSize (px)Frames

Keep every sheet the same size: one column per frame, 8 rows (directions: down, down-right, right, up-right, up, up-left, left, down-left). The game reads frame sizes from the normal sheet. CREDITS.txt in the .zip lists the original artists. The sprites are CC BY-NC 4.0 (from SpriteCollab), so a recolour has to credit them and stay non-commercial.
